# 起始工程资源

- `src/`、`scripts/`、`score.json` 与六秒几何示范：DeepSeek Code Cinema 原创，MIT。没有复制参考附件代码。
- `public/sound.wav`：运行 `npm run sound` 从原创 score 生成；MIT。它是工具示范音，不代表所有题材的合适配乐。
- `public/fonts/NotoSansSC.ttf`：Google Fonts / Noto Sans SC，SIL Open Font License 1.1；随附 `public/fonts/OFL.txt`。来源及固定快照见包内 SOURCES.md。
- Remotion 依赖按自身许可使用；React 为 MIT，TypeScript 为 Apache-2.0。安装时保留各依赖许可。Skill 的 MIT 不替代第三方条款。
