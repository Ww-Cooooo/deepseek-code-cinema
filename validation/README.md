# 验证记录

2026-10-19，试用版1.0.0-rc.3。以下分别记录工具可用、独立制作、人工验收、安装和发布状态。

## 宿主与隔离

主测Windows x64 / PowerShell7.6.5 / Node24.16.0 / npm11.13.0。官方`@deepseek-ai/dsh@0.2.1-rc.2`，实际provider/model为`deepseek-official / deepseek-flash`。前期业务high/32768，预算收尾使用low/16384或8192，声音有限任务off/8192或4096，最后故事片接触表复核off/512；知识片末次读图high/4096，安装只读检查high/8192。当天官方别名映射为DeepSeek-V4.1-Flash-1017，无法证明不可变的服务端检查点。

凭据由用户在官方设置保存，未读密钥正文。独立业务会话只暴露冻结Skill、正常任务、参考与基础工具，不含创建对话、另一片答案、旧包或私人Skill。测试允许本机打包器/浏览器子进程，是资料与提示隔离，非OS沙箱。默认Windows受限环境曾出现esbuild/Chrome EPERM，失败保留并计费。

## 包与真实执行

新包28文件。正式名称为DeepSeek Code Cinema，调用入口`/deepseek-code-cinema`；实际业务验证发生在改名前，输入与会话中原工作名`code-to-video`按原样保留。改名只涉及品牌和路径，没有改动创作方法及依赖版本。原创起始工程具备图形与Three.js空间两条路径、稳定逐帧动画、时序配置、中文字体和声音入口。实际完成安装、类型检查、两条路径与配置切换、代表帧读取、两秒/六秒有声渲染；ZIP解出后离线安装279包、类型检查与两条静帧通过。这些是工具验证，不作完整电影质量证据。

用户要求目标DeepSeek看参考并共同讨论；该共同开发实际读图、提出方法并写了中性starter。创建者复核、集成。共同开发与下面独立业务任务分开，不计一支代表影片。

## 失败、费用与安装

首轮二分查找片虽有50秒MP4与自修，用户否决整体风格；二维灯塔故事也未成为完整代表作品。失败、旧版本与费用均保留，没有作为通过样片发布。

原阶段200次请求全部结算，按核对日官方峰价估算4.186262元，包含失败与被否决作品。后来用户明确从新消息起重新计算总10元上限，包含共同开发、业务续作、失败/重试与安装检查；截至本次已507请求全部结算，峰价估算9.827663元，未知0，实际账单未知。

费用保护在每次HTTP前预留，可靠完整usage才结算，失败或未知保留预留。峰价估算为未命中输入2元/百万token、缓存读取0.04元/百万、输出8元/百万。历史预留记录不改；后续依据官方V4离线tokenizer对完整序列化JSON计数，使用2倍文本token、64k模板余量、每图2048token，与字节保守界取小，未知附件回退满上下文，输出按真实cap预留。实际usage必须不超预留界，未知不退款。总10元与旧账本不变，26项无密钥测试覆盖实际adapter拦截、重试、恢复与官方离线分词器。官方依据：[Token用量](https://api-docs.deepseek.com/quick_start/token_usage/)、[图像理解](https://api-docs.deepseek.com/guides/vision/)。
