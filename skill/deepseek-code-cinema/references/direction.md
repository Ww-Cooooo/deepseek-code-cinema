# 从主题到电影画面

## 先决定这支片值得看什么

一句话目标包含对象、变化与落点，例如“观众看见信息被压缩后仍能被重新读懂”。知识片需要理解，故事需要选择、反应与结果；产品片需要操作与可核查的变化。电影感服务这些内容，不能拿漂亮空镜替代内容。

先写一小段视觉方向：核心画面、视觉主语、空间或图形层级、尺度锚点、机位/运动、光与材质、声音的起落、文字角色。正常选择由你完成，不让用户填写专业问卷。有明确参考时，以实际画面落实方向；不能把用户要的电影感换成另一种更容易写的插画风格。

选择适合内容的表达，允许有意混合：

- **图形电影 / 2.5D**：数字、光点、路径、符号成为演员。通过尺度、层级、留白、虚实与匹配变化组织视线，DOM/SVG/canvas 可以成立。整张图一直漂动没有完成设计。
- **实体世界 / 3D**：主体处在可辨认的空间中，机位、透视、遮挡、方向光与材质共同解释关系。用 Remotion + Three.js，不能为了省事将它降成平涂背景。
- **衔接两者**：让光、形状、方向、物件或声音有意义地承接；例如近看一枚物体的纹理，拉开才发现它属于更大结构。两种技术不应只是两套素材轮流出现。

不用强制 A/B/C 标签、固定镜头数量、黑底或 3D。纸、线稿、图表、界面也可以成为电影语言；关键是它们怎样被观看和发生变化。用户明确要信息卡或教程时，尊重该用途。

## 将愿望变成画面决定

| 用户说 | 可用的决定 | 容易落空的做法 |
| --- | --- | --- |
| 史诗、宏大 | 用渺小主体、巨大空间/数量、时间跨度与有意停留建立压力；保留尺度锚点 | 放大背景、铺满粒子，却没有参照 |
| 镜头语言丰富 | 建立关系、接近细节、显示反应、拉开重看；运动/切换改变观众知道或感到的事 | 每镜机械推近，或同一版式换色 |
| 深刻、有意义 | 让选择有代价，变化带来后果，结尾改变开头的理解 | 最后贴一句哲理，画面没有兑现 |
| 高级、惊艳 | 主次明确、材质/光有选择、形变或揭示出乎预期又与内容有关 | 特效种类多、长品牌开场、所有东西均匀发光 |

这些是设计手段，不是效果保证；“获奖”“好莱坞级”属于愿望，不能作为已达到的宣传结论。

## 写可以拍出来的镜头表

工程里留下简短 `storyboard.md`。每镜记录：

`时段 | 叙事作用/主体动作 | 机位与景别/运动 | 空间或图形层级、光/材质 | 起止状态/衔接 | 声音/文字`

相关字段可以合并，不为填表写空话。先让观众认出主体，再看到变化和后果。新的空间/规则需要建立时间；重复动作可以加速；反转前可留白；结果要有停留。45–60 秒片不照搬长片的十几秒品牌片头。

“主体出现、标题出现、标题变大、换页”通常没有解决怎么拍。寻找路径、重排、选择、阻挡、积累、追逐、接触、反馈或释放；这些是创作词汇，不是全片必须用齐的清单。

| 任务 | 能承载关系的动作 | 不足以替代的东西 |
| --- | --- | --- |
| 机制/流程 | 输入走过路径，条件改变分支，返回结果影响路程/等待 | 画完流程图再整体浮动 |
| 比较 | 同一参照下，两种动作产生不同轨迹、范围与结果 | 两段标题旁各放一个无关图标 |
| 数量/时间 | 同源数据驱动密度、曲线、尺度、读数；关键状态停住 | 高速滚数，单位和结论没有同步 |
| 故事 | 所求、动作遇阻、反应与选择、可见后果；结尾重新理解最初物件 | 三张“困难/解决/成功”字幕卡 |
| 产品 | 可辨认的操作引出真实或标注为概念的状态变化 | 功能清单配装饰光，或伪造实测 |

## 设计视线、空间与光

一个镜头有一个主要观看关系。远景建立尺度，近景揭示细节；前景遮挡和中后景距离可以建立深度。相机移动要带来新信息或情绪，轨迹、焦点、速度都由帧推导；不是把无关视角随机串起来。

实体场景中，为主光、受光面、暗面/剪影、反射和空气远近作明确选择。先让轮廓、接触、距离与材质成立，再加辉光、颗粒和镜头效果。抽象图形不强求物理阴影，靠亮度/尺度/层级与虚实组织视线。粒子可以表现物质、记忆、群体或轨迹；其聚合、散开或流动应改变含义。

色彩、字形、光与材质有亲缘关系，镜头形式随内容变化。字可以是主角，但要有主次和停留。电影字幕卡与短字幕只在需要时进入；常驻章节栏、徽章、步骤条和大段解释容易把影片拉成界面。产品界面本身就是题材时，可有目的地保留。

转场从前后关系选择：形状/亮点/方向匹配、遮挡、动作接续、空间拉开、硬切、短叠化、失焦或黑场呼吸。实际看切点，避免两段字抢读。不要每场统一白闪、故障或长叠化；也别用模糊遮住尚未设计的动作。

## 从参考迁移，不复刻表皮

对关键片段记“看到什么 → 起什么作用 → 新内容怎样承接”。按需要检查世界/层级、机位、光、材质、尺度、运动/切换、字与声音。静帧只支持布局；有序帧支持采样变化；连续观看、听音和作者说法分别记录。

本包有两条方法参考，来源见 [SOURCES.md](../SOURCES.md)：

- 历史动画把微光、倒数、路线、网格、符号与地球通过尺度和形状关系连接起来，适合学习图形电影的层级、时间压缩与首尾回环；不需要把每个镜头改成 3D。
- 《潜光》的可见画面从太阳/海面/微小人群，转向光束、星际圆环与层层结构，再显影早先的场景。可学习空间尺度、光的主语、实体世界与抽象空间的衔接；没有拿到源码，不能仅凭成片断言每个渲染技术。

作者愿望式 Prompt 提供了“剧本、镜头、声音、少量字幕”的目标线索，不保证一次成功，也不是原始制作全过程。不能复制其场景、logo、音乐和未知许可工程；新片应有自己的世界、冲突/关系与落点。

## 事实、数据与原创

事实保留来源与核查日期，示意图标明示意。数值保留统一基准单位，图、标签、旁注与结论调用同一转换与数据。300000 年可以显示“300,000 年前”或“30 万年前”，不能拼成“300,000 万年前”。参考里的数值错误不能随风格继承。

产品能力、实测数据、史实和使用者经历都不能编造。没有外部事实时可做明确标注的概念/虚构故事；不要用一句“仅供参考”掩盖会误导观众的具体主张。
